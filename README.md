## About This Portfolio

This repository presents four reference projects covering financial modeling, data preparation, SQL analysis, machine learning, workflow automation, and Power BI reporting.

The projects demonstrate the following general workflow:

```text
Raw Data → Cleaning & Validation → Modeling → Analysis / ML → Reporting → Insights
```

> **Attribution:** These are curated reference projects. Original authors and source repositories are credited on every project page. Any personal implementation, modification, or learning notes should be documented separately and must not be represented as original work unless independently created.
